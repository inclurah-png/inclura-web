# Inclura

Inclura is a multilingual social platform focused on creators, organizations, NGOs, hospitals, governments, and communities.

## Features

- User authentication
- Feed
- Comments
- Emoji reactions
- Creator score
- Follow system
- Saved posts
- Cross-posting
- Multilingual interface
- Post translation
- Firebase backend
- Cloudflare Pages Functions

## Tech Stack

- React
- Vite
- Firebase
- Cloudflare Pages
- Cloudflare Functions
